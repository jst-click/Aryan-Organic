# ARYAN ORGANICS Website

Modern marketing website for **ARYAN ORGANICS** — automated organic terrace garden installation in Bangalore.

## Tech stack

- React 19 + Vite
- Tailwind CSS v4
- React Router
- Framer Motion
- Lucide React icons

## Getting started

```bash
cd website
npm install
npm run dev
```

Open the local URL shown in the terminal (usually `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```
